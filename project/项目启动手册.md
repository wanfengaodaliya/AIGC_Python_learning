## 项目概述

### 项目简介

AIGC（Artificial Intelligence General Computing）项目是一个整合了多个功能模块的全栈Web应用系统，包含用户认证、职业选择设置、AI智能对话和用户设置管理四大核心功能。

### 技术架构

**前端技术栈：**
- React 18 - 用户界面框架
- React Router v6 - 路由管理
- Vite - 构建工具
- Bootstrap 5 - UI组件库

**后端技术栈：**
- FastAPI - Web框架
- SQLAlchemy - ORM工具
- MySQL - 关系型数据库
- uvicorn - ASGI服务器

**项目结构：**
```

│   │   ├── src/
```

## 安装步骤

### 步骤一：克隆或下载项目

如果您使用Git，可以执行：

```bash
git clone <repository_url>
cd AIGC_Python_learning
```

如果您直接下载项目，请解压到指定目录。

### 步骤二：安装前端依赖

1. 进入前端项目目录：

```bash
cd project/frontend
```

2. 安装前端依赖：

```bash
npm install
```

3. 验证安装是否成功：

```bash
npm --version
node --version
```

### 步骤三：安装后端依赖

1. 进入后端项目目录：

```bash
cd project/backend
```

2. 安装后端依赖：

```bash
pip install -r requirements.txt
```

3. 验证安装是否成功：

```bash
pip list | grep -E "fastapi|uvicorn|sqlalchemy"
```

### 步骤四：配置MySQL数据库

1. 启动MySQL服务：

```bash
# Windows
net start mysql

# Linux/Mac
sudo systemctl start mysql
```

2. 创建数据库：

```bash
mysql -u root -p
```

在MySQL命令行中执行：

```sql
CREATE DATABASE IF NOT EXISTS ai_coding_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

3. 验证数据库配置（检查 `app/core/database.py` 中的配置）：

```python
DATABASE_URL = "mysql+pymysql://root:1234@localhost:3306/ai_coding_platform"
```

> **注意**：如果您的MySQL密码不是 `123456`，请修改 `app/core/database.py` 文件中的 `DB_PASSWORD` 配置。

- `1234`：数据库密码

## 启动流程

### 启动顺序

**重要**：请严格按照以下顺序启动服务，以确保系统正常运行。

#### 第一步：启动MySQL数据库

```bash
# Windows
net start mysql

# Linux/Mac
sudo systemctl start mysql
```

验证MySQL是否启动成功：

```bash
mysql -u root -p1234 -e "SELECT VERSION();"
```

#### 第二步：启动后端服务

1. 进入后端目录：

```bash
cd project/backend
```

2. 启动后端服务：

```bash
uvicorn main:app --reload --port 8000
```

3. 验证后端服务是否启动成功：

在浏览器中访问：`http://localhost:8000/api/v1/health`

应返回：
```json
{"status": "healthy"}
```

#### 第三步：启动前端服务

1. 新开一个终端窗口
2. 进入前端目录：

```bash
cd project/frontend
```

3. 启动前端服务：

```bash
npm run dev
```

4. 验证前端服务是否启动成功：

在浏览器中访问：`http://localhost:3000`

应看到用户登录界面。

## 常见问题解决方法

### 问题一：前端无法连接后端API

**症状**：
- 浏览器控制台显示 `net::ERR_CONNECTION_REFUSED`
- 前端页面显示 "网络错误"

**解决方法**：

1. 确认后端服务是否启动：

```bash
# 检查后端进程
tasklist | findstr python
```

2. 确认后端服务端口是否正确：

```bash
netstat -an | findstr 8000
```

3. 确认防火墙设置：

```bash
# Windows 允许端口通过防火墙
netsh firewall add portopening TCP 8000 "Backend API"
```

### 问题二：数据库连接失败

**症状**：
- 后端日志显示 `Connection refused`
- 或 `Access denied for user`

**解决方法**：

1. 确认MySQL服务是否启动：

```bash
net start mysql
```

2. 验证MySQL用户名和密码：

```bash
mysql -u root -p1234
```

3. 检查数据库是否存在：

```sql
SHOW DATABASES;
```

4. 如果数据库不存在，创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS ai_coding_platform CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 问题三：依赖安装失败

**症状**：
- `npm install` 报错
- `pip install` 报错

**解决方法**：

1. 清理缓存后重新安装：

```bash
# npm
npm cache clean --force
rm -rf node_modules
npm install

# pip
pip cache purge
pip install -r requirements.txt --no-cache-dir
```

2. 检查Python版本：

```bash
python --version
```

确保Python版本在3.9以上。

### 问题四：端口被占用

**症状**：
- 启动时显示 `Port 8000 is already in use`
- 或 `Port 3000 is already in use`

**解决方法**：

1. 查找占用端口的进程：

```bash
netstat -ano | findstr 8000
```

2. 结束占用端口的进程：

```bash
taskkill /PID <进程ID> /F
```

3. 或修改端口号：

```bash
# 后端
uvicorn main:app --reload --port 8001

# 前端
# 修改 vite.config.js 中的 port 配置
```

### 问题五：bcrypt密码哈希错误

**症状**：
- 用户注册时提示 "密码哈希失败"
- 后端日志显示 bcrypt 相关错误

**解决方法**：

确保passlib和bcrypt正确安装：

```bash
pip install passlib[bcrypt]
```

### 问题六：跨域请求失败

**症状**：
- 浏览器控制台显示 CORS 错误
- `Access-Control-Allow-Origin` 错误

**解决方法**：

检查后端的CORS配置（`main.py`）：

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 生产环境应设置具体域名
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 注意事项

### 安全注意事项

1. **生产环境配置**
   - 修改默认的数据库密码
   - 使用强密码作为JWT密钥
   - 将CORS的`allow_origins`设置为具体域名

2. **敏感信息保护**
   - 不要将密码和密钥提交到版本控制系统
   - 使用环境变量存储敏感配置

3. **API安全**
   - 生产环境应启用HTTPS
   - 实施请求频率限制
   - 添加API密钥验证

### 开发注意事项

1. **代码规范**
   - 遵循项目的代码风格
   - 编写有意义的注释
   - 保持函数简短单一职责

2. **Git提交规范**
   - 提交前进行代码审查
   - 使用语义化的提交信息
   - 不要提交敏感信息

3. **测试**
   - 新功能开发前先写测试用例
   - 定期运行完整测试套件
   - 修复bug后添加回归测试

### 性能注意事项

1. **数据库优化**
   - 为常用查询字段添加索引
   - 使用连接池管理数据库连接
   - 定期清理无用数据

2. **前端优化**
   - 使用代码分割减少初始加载时间
   - 实施懒加载策略
   - 优化图片和静态资源

3. **后端优化**
   - 使用缓存减少数据库查询
   - 实施请求限流
   - 异步处理耗时任务

### 维护注意事项

1. **日志管理**
   - 定期检查日志文件
   - 设置日志轮转
   - 监控错误日志

2. **数据备份**
   - 定期备份数据库
   - 备份配置文件
   - 测试恢复流程

3. **依赖更新**
   - 定期检查安全更新
   - 测试新版本兼容性
   - 记录重大更新内容
