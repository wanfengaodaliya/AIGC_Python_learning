# 部署说明

## 1. 开发环境配置

### 1.1 系统要求

- Python 3.8+
- MySQL 5.7+
- pip

### 1.2 依赖安装

1. 进入后端目录：
   ```bash
   cd backend
   ```

2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

### 1.3 数据库配置

1. 确保MySQL服务正在运行
2. 执行数据库初始化脚本：
   ```bash
   python init_db.py
   ```

### 1.4 启动开发服务器

```bash
uvicorn main:app --reload
```

服务器将在 `http://localhost:8000` 启动。

## 2. 生产环境部署

### 2.1 环境准备

- 安装Python 3.8+
- 安装MySQL 5.7+
- 安装Nginx（可选，用于反向代理）

### 2.2 依赖安装

```bash
pip install -r requirements.txt
```

### 2.3 配置文件修改

1. 编辑 `config.py` 文件，修改以下配置：
   - `SECRET_KEY`：设置为强随机字符串
   - `DB_PASSWORD`：设置为生产环境数据库密码
   - 其他配置根据实际情况调整

### 2.4 数据库初始化

```bash
python init_db.py
```

### 2.5 启动生产服务器

使用Gunicorn作为生产服务器：

```bash
pip install gunicorn
```

启动命令：

```bash
gunicorn -w 4 -k uvicorn.workers.UvicornWorker main:app
```

### 2.6 Nginx配置（可选）

```nginx
server {
    listen 80;
    server_name example.com;

    location / {
        proxy_pass http://localhost:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

## 4. 常见问题排查

### 4.1 数据库连接失败

- 检查MySQL服务是否正在运行
- 检查数据库连接信息是否正确
- 检查防火墙是否允许MySQL端口访问

### 4.2 启动服务器失败

- 检查端口是否被占用
- 检查依赖是否安装完整
- 检查配置文件是否正确

### 4.3 API请求失败

- 检查请求参数是否正确
- 检查JWT令牌是否有效
- 检查数据库连接是否正常

### 4.4 密码重置功能问题

- 检查手机号是否正确
- 检查密码长度是否符合要求
- 检查数据库中是否存在该用户

## 5. 安全建议

- 使用HTTPS协议
- 定期更新依赖包
- 配置适当的CORS策略
- 实施请求频率限制
- 定期备份数据库
