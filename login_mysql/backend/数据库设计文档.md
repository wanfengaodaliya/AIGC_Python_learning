# 数据库设计文档

## 1. 数据库概述

本系统使用MySQL数据库，数据库名称为`auth_system`，用于存储用户认证相关的信息。

## 2. 表结构设计

### 2.1 users表

| 字段名 | 数据类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| `id` | `INT` | `AUTO_INCREMENT PRIMARY KEY` | 用户ID，自增主键 |
| `username` | `VARCHAR(50)` | `NOT NULL UNIQUE` | 用户名，唯一 |
| `password` | `VARCHAR(255)` | `NOT NULL` | 密码，加密存储 |
| `phone` | `VARCHAR(20)` | `NOT NULL UNIQUE` | 手机号，唯一 |
| `created_at` | `TIMESTAMP` | `DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `last_login` | `TIMESTAMP` | `NULL` | 最后登录时间 |
| `status` | `ENUM('enabled', 'disabled')` | `DEFAULT 'enabled'` | 账户状态 |

### 2.2 索引设计

| 索引名 | 类型 | 字段 | 描述 |
| :--- | :--- | :--- | :--- |
| `PRIMARY` | 主键索引 | `id` | 唯一标识用户 |
| `idx_username` | 普通索引 | `username` | 加速用户名查询 |
| `idx_phone` | 普通索引 | `phone` | 加速手机号查询 |
| `idx_status` | 普通索引 | `status` | 加速状态查询 |

## 3. 数据类型说明

| 字段类型 | 长度 | 说明 |
| :--- | :--- | :--- |
| `INT` | 4字节 | 用于存储整数，如用户ID |
| `VARCHAR(50)` | 最大50字符 | 用于存储用户名 |
| `VARCHAR(255)` | 最大255字符 | 用于存储加密后的密码 |
| `VARCHAR(20)` | 最大20字符 | 用于存储手机号 |
| `TIMESTAMP` | - | 用于存储时间戳 |
| `ENUM` | - | 用于存储枚举值，如账户状态 |

## 4. 表结构SQL语句

```sql
CREATE TABLE IF NOT EXISTS users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    phone VARCHAR(20) NOT NULL UNIQUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_login TIMESTAMP NULL,
    status ENUM('enabled', 'disabled') DEFAULT 'enabled',
    INDEX idx_username (username),
    INDEX idx_phone (phone),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```
